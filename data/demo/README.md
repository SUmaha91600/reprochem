# Fichiers de la démo

voir `data/corpus_manifest.csv`), modifiées pour la démo et la red team
(`scripts/red_team.py`) :

  cas d'échec montré en démo.

Ce ne sont pas les articles publiés : ne pas les citer comme tels.
